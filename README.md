# Hardleaf VR prototype

Research prototype for a master's thesis on negotiating feasible design spaces in VR, using the Hardleaf Pavilion (Gramazio Kohler Research, ETH Zurich) as the case.

This public copy shows precomputed options only. Live recalculation and new options need the local Python bridge, which is not part of this copy.

Assumed date, site, use and targets are placeholders. Geometry only: structure and joints are not checked. See `docs/SOURCES.md`.
